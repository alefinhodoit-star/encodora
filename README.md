# Encodora · Engenharia de Software de Precisão

Agência de engenharia de software especializada em backend, frontend, mobile, cloud/DevOps e inteligência artificial.

## Tecnologias

- **Frontend**: React 18, Next.js 14 (App Router), TypeScript
- **UI**: Tailwind CSS, Shadcn/ui, Radix UI
- **Estado**: React Query
- **Formulários**: React Hook Form com Zod
- **Animações**: Framer Motion
- **Ícones**: Lucide React
- **Testes**: Jest, React Testing Library
- **Linting**: ESLint
- **Type Checking**: TypeScript

## Instalação

```bash
npm install
```

## Desenvolvimento Local

```bash
npm run dev
```

Abra `http://localhost:3000` para ver o aplicativo.

## Construção para Produção

```bash
npm run build
```

```bash
npm start
```

## Scripts Disponíveis

- `npm run dev`: Inicia o servidor de desenvolvimento
- `npm run build`: Constrói o aplicativo para produção
- `npm run start`: Inicia o servidor de produção
- `npm run lint`: Executa o ESLint
- `npm run typecheck`: Executa o TypeScript

## Estrutura do Projeto

```
app/
  layout.tsx           # Root layout
  page.tsx             # Home page
  login/page.tsx       # Login page
  register/page.tsx    # Register page
  blog/                # Blog routes
  portfolio/           # Portfolio routes
  servicos/page.tsx     # Services page
  sobre/page.tsx        # About page
  galeria/page.tsx      # Gallery page
  termos-de-uso/page.tsx # Terms page
  privacidade/page.tsx   # Privacy page
  admin/                # Admin routes
components/            # UI components
lib/                   # Application libraries
hooks/                 # Custom hooks
types/                 # TypeScript types
```

## Como Começar

1. Clone este repositório
2. Execute `npm install` para instalar as dependências
3. Execute `npm run dev` para iniciar o servidor de desenvolvimento
4. Abra `http://localhost:3000` no seu navegador
5. Faça alterações e veja-as instantaneamente

## Como Construir

1. Faça alterações nos arquivos em `app/`, `components/`, `lib/`, etc.
2. Execute `npm run typecheck` para verificar o TypeScript
3. Execute `npm run lint` para verificar a qualidade do código
4. Execute `npm run build` para verificar a construção para produção

## Como Testar

1. Execute `npm test` para executar os testes
2. Execute `npm run lint` para verificar a qualidade do código
3. Execute `npm run typecheck` para verificar o TypeScript
4. Execute `npm run build` para verificar a construção para produção

## Como Implantar

1. Execute `npm run build` para construir o aplicativo
2. Execute `npm start` para iniciar o servidor de produção
3. O aplicativo estará disponível em `http://localhost:3000`

## Como Manter

1. Monitore o desempenho com as ferramentas de monitoramento
2. Monitore os logs com as ferramentas de logging
3. Monitore a saúde com as ferramentas de saúde
4. Faça backup regularmente
5. Mantenha o software atualizado
6. Faça testes regularmente
7. Faça revisões de código regularmente
8. Faça documentações regularmente
